# 酒店管理系统（连锁多门店）

面向连锁酒店集团的云上管控平台：总部统一管理会员、房价、渠道、协议客户与品牌标准，门店独立运营日常接待业务，总部实时汇总全集团经营数据。

## ✨ 核心亮点

| 亮点 | 说明 |
|------|------|
| 🛎️ **OTA 渠道直连** | 房态房价订单自动同步美团/同程/携程/飞猪，空房自动上架、售罄自动下架、订单自动进系统 |
| 🛡️ **超卖自动防护** | 渠道配额 + 原子扣减，最后一间房多渠道同时来单时自动拒单，零超卖 |
| 🧹 **客房清洁管理** | 退房自动派单，清洁进度追踪，查房通过自动上架 OTA |
| 🌙 **夜审日结** | 每日自动对账，异常检测，营业日锁定防篡改 |
| 🧾 **发票管理** | 抬头记忆、关联账单一键开票、发票号自动生成、可追溯 |
| 🏢 **连锁统一管控** | 总部统一标准，门店独立运营，数据实时汇总 |

## 业务闭环

```
预订 → 入住 → 在住管理（换房/续住/消费/收款） → 退房结账 → 客房清洁 → 夜审 → 报表分析
                    ↓
              OTA 渠道直连（房态/房价/订单自动同步）
```

## 功能模块

### 前台业务
- **房态图**：可视化房态（空净/空脏/住客/维修/预留），房间操作、楼层管理
- **在住管理**：入住、退房、换房、续住、附加消费、中途收款、账单查询
- **预订管理**：新建/修改/取消/No-show、预订转入住、房型库存冲突检测
- **客房清洁**：退房自动派单、清洁任务流转（待分配→清洁中→待查房→已完成）
- **夜审管理**：营业日结、自动补过账、异常检测、历史记录

### 客户管理
- **客户档案**：客户信息、黑名单标签、关联会员
- **会员管理**：等级、积分、储值余额、充值、积分调整

### 财务管理
- **发票管理**：发票抬头（个人/企业）、关联账单开票、发票作废、汇总统计

### 系统设置
- **房价管理**：房价方案、房价日历、价格审计
- **OTA 渠道对接**：渠道配置、房型映射、渠道配额、推送日志、OTA 订单
- **用户管理**：员工账号、角色权限、门店数据权限
- **操作日志**：关键操作审计追溯

## OTA 渠道直连（核心亮点）

### 工作原理

```
PMS 房态变化 ──自动触发──▶ 计算可售 = min(空净房, 配额-已用)
                              ├─ 可售>0 → 推 open（上架）
                              └─ 可售=0 → 推 close（下架）

OTA 来单 ──回调/拉取──▶ 系统接收订单
                          ├─ 配额够 → 自动建 PMS 预订 + 扣配额 + 推库存
                          └─ 配额不足 → 自动拒单（超卖防护）
```

### 触发点（房态变化自动同步）

入住、退房、换房、改房态、查房通过、改房价 —— 均自动触发 OTA 推送，无需人工干预。

### 超卖防护

- 为每渠道每房型设置可售配额
- 接单时原子扣减配额（数据库层面保证并发安全）
- 配额不足自动拒单："配额不足，无法接单（超卖防护）"

> 当前为模拟 API 层（`callChannelAPI`），真实对接各 OTA 平台只需替换该函数，业务逻辑无需改动。

## 快速启动

### 1. 启动数据库（PostgreSQL）

```bash
docker compose up -d db
```

或使用已有 PostgreSQL，配置环境变量（见下方）。

### 2. 启动后端

```bash
cd server
go run .
```

环境变量（缺省用本地开发默认值）：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DB_HOST` | localhost | 数据库主机 |
| `DB_PORT` | 5432 | 数据库端口 |
| `DB_USER` | hotel | 用户名 |
| `DB_PASSWORD` | hotel123 | 密码 |
| `DB_NAME` | hotel_management | 库名 |
| `PORT` | 8080 | 后端监听端口 |

### 3. 启动前端

```bash
cd web
npm install
npm run dev
```

访问 `http://localhost:5173`

### 4. Docker 一键部署

```bash
docker compose up -d
```
